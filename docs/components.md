# 模块职责

| 文件 | 职责 |
| --- | --- |
| `珀研Q4资金预测看板v9.html` | 基础界面、流水导入、规则、人工确认、图表、旧报表和 CSV 导出 |
| `数仓/eco_module.js` | 计划提报审批、参数账期、生态比对、滚动预测、数仓启动与界面联动 |
| `数仓/build_v10.py` | 把基础页面与生态模块合成为默认运行页面 |
| `数仓/server.py` | HTTP 路由、上传下载、模板、审批编排、计划同步、数仓浏览页 |
| `数仓/db.py` | SQLite 连接、流水去重、人工标签、规则、流水编辑日志、余额、分类快照 |
| `数仓/db_eco.py` | 字典、参数、账期、桥接、提报、审批状态、附页和匹配记录 |
| `数仓/plan_parse.py` | 识别预算明细、字典/主体/汇率，计算人民币金额，输出 G1/G2/G3 报告 |
| `数仓/claim_parse.py` | 按 C-01 至 C-09 将销售/部门费用/人力源表转换为月计划 |
| `数仓/etl.py` | 命令行导入、导出、状态与清空；部分旧口径计划可直接写入，需谨慎使用 |
| `数仓/template_export.py` | 根据当前字典生成空白计划模板和空白流水模板 |
| `数仓/schema.sql` | 基础与生态数据表定义 |
| `数仓/defaults.json` | 通用科目、桥接和参数；不含业务记录 |
| `数仓/seed_eco.py` | 幂等补齐配置与模板注册；新增币种参数补齐 |
| `数仓/start.ps1` / `启动数仓.bat` | Windows 解释器发现、端口检查、后台启动与打开浏览器 |
| `scripts/check_release.py` | 检查 Git 暂存内容与页面内嵌数据，阻止误发布本地数据 |

运行后出现的 `warehouse.db`、uploads、日志、pid 均为本地状态，不属于源码。
