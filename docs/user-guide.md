# 使用指南

## 安装后的空白状态

首次启动无流水、预算、客户、主体与银行账户。基础科目、桥接、通用参数、人民币汇率和空白模板可直接使用。安全线默认 0，不能据此判断实际资金是否充足。

打开「计划提报与审批」下载计划模板。模板有预算明细、科目字典、主体台账、记账汇率四张表：

- 在主体台账填写公司全称、板块、境内外、币种；其余账户、合并、归集、负责人、备注按实际维护。
- 在预算明细填写公司、方向、科目和正数金额；科目从字典选取，资金时点可填上旬/中旬/下旬。大额需备注。
- 外币在记账汇率表补齐币种和折人民币汇率。上传后会在参数中心生成该币种汇率参数，后续人工设置优先。
- 上传时明确选择期间。文件名与期间不一致的提示需人工核对，不会自动改写你的选择。

直接上传空白模板会提示没有数据行，这是正常情况。模板包含真实配置后将只保存在本地。

## 流水导入与确认

银行流水可用 XLSX 或 CSV；旧 `.xls` 请先另存。预览确认日期、金额、借贷方向、对方名称及摘要，再执行导入。优先从未匹配项目补规则或人工确认；可以只改一级/二级/现金流中的部分字段。

人工批量修改后点击对应保存按钮，查看是否提示已经保存到数仓。连接失败时草稿保留，恢复后重试。在保存成功前不要清理浏览器数据或切换到另一浏览器/端口；这些操作不会迁移当前草稿。

「重置导入预览」只重置当前预览；修改已存档数据使用存档编辑入口。日期、金额、对方名称修改会迁移人工标签。若遇同日同金额同对手多笔交易，需核对当前业务键是否把它们视作同组。

## 刷新与重新测试

普通刷新不清空测试内容。流水导入需等顶部出现「导入数据已保存」；保存失败时保留本机草稿，可点击「重试保存导入数据」，刷新后也会恢复并尝试保存。未保存草稿依赖当前浏览器及端口，浏览器空间不足时会明确提示；文件仍在解析时应等待解析完成。

页面会记住当前模块、流水审核步骤、计划步骤与选择、期间和操作人，以及已有参数/人工确认草稿。已审批计划、流水等正式内容由本地数据库保存。

要开始全新测试，点击页面顶部的「重置测试数据」，阅读确认提示后选择确定。此操作清空流水、计划、审批与导入记录、人工确认、主体、客户、自定义规则和参数，基础科目、桥接、默认参数与空白模板恢复初始值；当前浏览器的本项目草稿同时清理。取消确认不会清空任何内容。

重置前自动在当前数据库同目录的 `backup/reset-时间-编号/` 备份 `warehouse.db`、`uploads/`（若存在）和 `browser-state.json`（当前浏览器草稿）。备份失败则不清空；重置成功后页面顶部显示备份目录。备份保留在本机，不随重置删除。需要恢复数据库时，先停止对应服务，再按下方备份说明恢复；浏览器草稿备份保留作人工恢复依据。

其他已打开的旧页面会被拒绝写入，刷新后切换到重置后的新状态；其他浏览器中的未提交草稿无法由本页备份。重置只影响当前地址对应的项目，不影响其他端口运行的项目副本。

## 计划审批

查看上传解析与 G1/G2/G3 报告，修正问题后重传或按实际情况处理。草稿点击提交后待审，批准后锁定；退回必须填写原因。审批操作人是用户填写的留痕信息。

已锁定计划需要变更时创建新版本，旧版在新版批准前继续有效。已核销期间再次上传时先核对版本和取数范围，以免重复。不要使用旧计划导入接口代替正常审批。

源预算自动拆解支持销售、部门费用和人力表，但需要确定唯一主体。多主体请使用标准预算明细模板逐行填写主体。

## 参数、预测与预实

在参数中心调整安全线、默认账期、当月回款比例、采购账期和预测期数。客户账期可以为 0；客户列表不预置，开发集成可通过 `/api/terms` 维护完整客户定义。界面已有客户行支持修改账期。

预测期末余额取上一月实际余额加累计预测净流。缺上月余额会提示待补，不输出安全判断。预实比对可按期间、主体、窗口查看差异和未匹配流水，补齐科目桥接后重新分析。参数是否实际驱动模型，请查功能清单。

## 导出与备份

页面可导出报表 CSV，数仓导出提供流水、旧计划和人工标签 Excel。这不是完整数据库备份。完整备份应先结束服务，再把 `数仓/warehouse.db`、同目录仍存在的 WAL/SHM 文件及 `数仓/uploads/` 一并复制到私有备份目录；运行中备份数据库应使用 SQLite backup API，不直接复制单个 DB 文件。

恢复时先关闭对应服务，确认备份来源和目录，再恢复数据库与上传原件；重新启动后核对记录数。浏览器未提交草稿不在数据库备份中，应先完成保存。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面提示数仓未连接 | 启动 Python 服务，通过 HTTP 地址打开，检查日志和端口 |
| 端口被其他项目使用 | 用 `WH_PORT` 设空闲端口；确认 health 中 db 指向当前项目 |
| 找不到 Python/openpyxl | 安装虚拟环境与 requirements，或设置 `FINANCE_PYTHON` |
| 模板按钮失败 | 确认服务已启动且初始化完成；模板由服务生成 |
| XLSX 解析失败 | 检查文件格式、表头、公式缓存；旧 XLS 转 XLSX，流水也可转 CSV |
| 刷新后某修改仍为旧值 | 检查保存提示、待保存草稿、是否切换浏览器/端口或打开另一份项目 |
| 计划不参与预测 | 确认已批准锁定，筛选期间与主体正确，检查日志中的同步错误 |
| 参数改了未影响计算 | 查看功能清单中的参数用途；预留参数尚未全部接入算法 |
