# 发布范围与数据保护

本仓库发布运行源码、基础分类配置、空白模板生成器、构建产物、测试代码和文档。公开发布不携带用户工作数据，原运行目录与数据库无需搬迁。

排除项：所有 SQLite 数据库及 WAL/SHM、真实或测试 Excel/CSV、预算与流水样例、上传原件、截图、数据库导出、备份、旧归档、临时浏览器资料、日志、pid、node_modules、虚拟环境、缓存及本地工具配置。

基础页面内嵌的历史流水、预算、余额、客户与财务结论已清理；个人及具体交易对手默认规则已去除，保留通用关键词分类算法。原项目品牌文件名为兼容构建路径保留，不表示仓库携带该公司的账务数据。

`数仓/defaults.json` 是非交易性的基础配置：科目、科目桥接、模型参数及人民币汇率。没有主体台账、银行账户、客户账期或计划明细。新用户应按自身业务校准分类、阈值、账期和税率。

测试源码中的虚构字段仅用于断言，执行时生成临时数据库/工作簿，结束后删除；仓库不提交测试运行产生的文件，也不读取工作数据库作为测试前提。

发布前运行 `python scripts/check_release.py`。它检查 Git 暂存文件名与内容、内嵌 DATA、初始化配置和常见凭据特征。该检查用于减少误提交，不能替代人工查看 `git diff --cached`。

历史业务需求文档和旧修复记录混有本地路径与财务实例，本次以源码核对后的中文文档重新整理，未直接发布原件。仓库保留原有远端提交历史，不重写已有历史。
